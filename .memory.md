> **Ecosystem note (BANcode v1.1.0):** Storage itself carries no BANcode /
> fingerprint / diagnostic references — corruption and state telemetry are
> surfaced by sibling layers, not here. The boot/kernel path (MBL and vip)
> raise BANcode codepoints from the canonical C+/W+/S+/B+ registry blocks in
> the default **System mode** (`BANCODE_DEFAULT_MODE == BANCODE_MODE_SYSTEM`),
> where fatal codes dispatch through Kernel Security Traps; **App mode**
> (`BANCODE_MODE_APP`) delivers them to an application-level crash handler
> instead. Both modes share the identical codepoint registry, so volume
> state observed as W+ WARNcode / C+ COMcode telemetry keeps identical
> meaning regardless of operating mode.

## 2. Mandatory Core Driver Modules

1. **Hardware Translation Layer (HTL)**: `htl_device_t` with `htl_read_block`, `htl_write_block`, `htl_flush_cache`.
2. **Corruption Detection & Checksumming**: `ow_crc32c` (polynomial `0x82F63B78`) and `ow_fletcher64`. Superblock, Inode, and Catalog headers contain embedded CRC32c checksums computed with their checksum fields zeroed.
3. **Power-Cut Protection & State Locking**: Real-time state flags (`OWFS_STATE_DIRTY`, `USFS_STATE_DIRTY`). On ungraceful shutdown, volume locks on mount and requires `owfs_consistency_check` / `usfs_consistency_check`.
4. **Direct Synchronous Flush**: Bare-metal disk sync (`owfs_sync_changes`, `usfs_flush_dirty`) calling `htl_flush_cache()` after metadata writes.
5. **Formatting Protocols**: Bare-metal volume synthesis (`owfs_format_volume`, `usfs_format_volume`) reserving MBL region, initializing allocation bitmaps, and creating Root Catalog (`/`).
6. **Erasure & Secure Sanitization Protocols**: Quick format, full scrub (0x00 sector overwrite), and cryptographic purge (`usfs_crypto_purge`, `owfs_crypto_purge`).
7. **Identity & Access Control**: `ow_sec` current-principal model. Entry/inode `owner_uid`/`owner_gid` + 9-bit rwx enforced on file/catalog operations; `SEC_READONLY` blocks all writes; `SEC_HIDDEN` restricts visibility to owner/superuser.
8. **Data-At-Rest Encryption**: ChaCha20 keystream per physical block (counter = block number, 12-byte per-volume nonce drawn from `htl_device_t.entropy` at format). OWFS v1.2 adds full encryption parity with USFS.

## 3. Strict Compliance Constraints

1. **Freestanding C99**: `-std=c99 -nostdlib -ffreestanding`. Hosted headers forbidden. Custom memory routines (`ow_memcpy`, `ow_memset`, `ow_memcmp`).
2. **Hex Alignment**: Block size `0x1000` (4096B), Inode/Catalog size `0x100` (256B), packed structs (`__attribute__((packed))`).
3. **Static Libraries**: Compiles `libowfs.a` and `libusfs.a` with standard include guards (`#ifndef OWFS_TYPES_H`, `#ifndef USFS_TYPES_H`).
